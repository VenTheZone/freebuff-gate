## 2026-08-15 — Desktop auto-start implemented

- Added opt-in `--auto-start` and explicit `--no-auto-start`; omitted flag preserves an existing setting during reinstall and leaves new installs disabled.
- Linux writes `~/.config/systemd/user/freebuff-mobile-connect.service`, reloads/enables/restarts through `systemctl --user`, and removes/stops/disables it on request or uninstall.
- macOS writes `~/Library/LaunchAgents/com.freebuff.mobile-connect.plist`, bootstraps/kickstarts current GUI user through `launchctl`, and boots it out on disable/uninstall.
- Windows creates/deletes `Freebuff Mobile Connect` Task Scheduler task through `schtasks.exe` with `ONLOGON` and `LIMITED` run level.
- Startup definitions execute managed Node wrapper, preserve credential/config handling, and record registration metadata in installer manifest. No admin elevation or system-wide service is used.
- Added command-injectable platform lifecycle tests, path/definition assertions, and docs. Real host service registration was not run in this Linux workspace.
