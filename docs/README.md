# Freebuff Gate documentation

- [install.md](install.md): install the desktop orchestrator, tailnet proxy, server-side folder browser, mobile relay, and Android app. The file is formatted as a copy-paste agent prompt.
- [mobile.md](mobile.md): adapt Gate Desktop for phones and tablets.
- [release-setup-binary.md](release-setup-binary.md): setup binary artifacts, checksums, signing status, and prerelease workflow steps.
- [../docker/relay/README.md](../docker/relay/README.md): self-host the mobile relay with Caddy and Let's Encrypt, or use Tailscale for private access.
- [ads-zero-fill.md](ads-zero-fill.md): troubleshoot empty ad responses, with root cause, fixes, and support contacts.
- [planning/](planning/): task plans and status. These files are not needed to run or build the project.
